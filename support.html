Manual installation · 手动安装版

Download Revisit 0.4.2 · 下载手动安装包. Version 0.4.2 is awaiting Chrome Web Store review. This manual installation package is available now and requires the following steps.

  1. Download and extract the ZIP to a folder you will keep.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Click Load unpacked and select the extracted folder containing manifest.json. Select that folder directly, not the ZIP or its parent folder.
  4. Read and agree to local storage in Revisit's setup page. Sign in to the website whose bookmarks you want to revisit.
  5. For your first use of X and of Mastodon, separately open that platform's bookmarks and keep scrolling while older batches load. Then return to Home.

首次使用 X 和长毛象，都要打开各自书签页并持续向下滚动加载旧书签。 Only loaded bookmarks can be resurfaced; the first few posts do not represent your complete library.

Getting started

In Revisit 0.4.2, read the collection notice and explicitly agree. A fresh installation does not ask you to create a password. Sign in to X or Mastodon at m.cmx.im. Revisit automatically shows the corresponding account's collected bookmarks on that platform's Home page; no platform selector is needed.

First use on X and Mastodon: load older bookmarks

On each platform's first use, open its native bookmark page and keep scrolling down, waiting for every older batch to load. For X, open History and use the Bookmarks section. For Mastodon, open m.cmx.im/bookmarks. Opening only the first page includes only recent saves. Only loaded bookmarks can be resurfaced, and the collected count is not your total bookmark count. Return to that platform's Home page to review the collected posts.

On X, you can also explicitly agree to “Load more bookmarks for display” in the Revisit popup. It uses the signed-in X web session, works in batches and can be stopped. X may limit or block requests. Mastodon's older-bookmark entry opens its native bookmark page and asks you to continue scrolling; it does not start X's reader or an independent authorization flow.

A bookmark or number is missing

Only bookmarks loaded through the website or the separately agreed X load-more control enter the local pool. Revisit's Home totals are collected snapshots. Revisit the corresponding bookmark page to update them. Platforms and accounts remain separate, even when usernames match. Changes to either website can affect collection or actions.

An avatar is missing

The website's avatar file may no longer be available. Revisit tries a distinct website-provided alternate image when available, then shows a bundled default avatar if the image cannot load. This does not delete the saved post or its display history.

No routine password

After first agreement, Revisit uses its local device key automatically, including after a Chrome restart. The non-extractable key and encrypted records are in the same profile. This is not the same protection as a separate password and does not protect against someone who can read or copy the whole profile.

Upgrading a 0.2.0 store

A valid old unlocked session can migrate saved posts and counts automatically. Otherwise enter the old local password once for migration; do not choose a new password. After migration, normal use does not require that password. If it is forgotten and no valid session can open the old store, you can clear local data and recollect from the corresponding website. Do not email the old password to support.

Removing local data and stopping collection

Clear local data removes encrypted content, display history, the device key and consent, without deleting bookmarks on X or Mastodon. Collection remains off until you explicitly agree again, with no new-password step. Uninstalling removes local extension data. The Home switch only hides the card. Close bookmark pages to stop ordinary collection, turn off the optional browsing setting to stop that additional collection, and use Stop to end X's optional load-more task. Disabling or uninstalling the extension stops all collection.

Reporting a problem

Include your Chrome version, Revisit version and the steps that caused the problem. Remove private content from any screenshot. Do not send passwords, cookies, authorization headers or session tokens.
